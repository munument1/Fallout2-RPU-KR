# RPU 한국어 v2.4.34-native.2 (넥서스 2.4.34-kr1.3)

## 수정 사항

- 영상 재생기가 읽는 `.sve` 확장자를 번역 ZIP에 포함합니다. `.txt` 엔딩 자막 번역만으로 해결되지 않던 영상 자막 누락을 수정합니다.
- 기존 한국어판의 장로·꿈·내레이션 등 시간 자막 22개를 복원하고, RPU 유조선 영상 자막을 남녀용으로 추가 번역했습니다. 모든 24개 파일을 CP949로 배포합니다.
- `elder.sve` 후반의 잘못된 `125` 프레임을 `1025`로 수정하여 자막이 시간순으로 재생되도록 했습니다.
- 기존 native.1의 엔딩 번역 및 공식 RPU 2.4.34용 HRP 기록창 수정도 포함합니다.

## 함께 설치할 엔진

[Korean Text Engine v1.2.4](https://github.com/munument1/Fallout2-Korean-Text-Engine/releases/tag/v1.2.4)의 외형 설명 수정을 함께 사용하세요. v1.2.3에서는 sfall 외형 창의 별도 1바이트 줄바꿈 경로가 남아 있었습니다. 외형 수정은 공식 sfall 4.5.1의 확인된 코드에만 적용하며, 사용자 PC나 Windows 11 문제로 확정하지 않았습니다.

번역 ZIP을 먼저 덮어쓰고 기존 엔진 설치기의 복구 기능으로 이전 엔진을 복구한 다음 v1.2.4를 설치하세요. 게임 폴더와 세이브를 먼저 백업하세요. 엔진 복구는 번역 ZIP에 포함된 파일을 제거하지 않습니다.

통합 ZIP의 `f2_res.dll`은 공식 RPU 2.4.34 원본 전용입니다. 다른 HRP나 모드팩은 번역 전용 `korean-classic-data.zip`을 사용하세요.

## 검증 범위

번역 자동 검사 7개: 전체 시간 자막의 증가하는 프레임 번호·한글·CP949 검사, ZIP에 포함된 24개 SVE 파일과 매니페스트 해시 일치, 기존 엔딩 자막 회귀 검사. 엔진 측에서는 실제 외형 설명 13개가 돋움 11 기준 4~9줄 이내에 원문 전체를 보존하는지 검사했습니다.

실제 RPU 프로세스에서 외형 함수가 새 어댑터로 연결된 것도 메모리 읽기로 확인했습니다. 화면 자동화 도구의 창 연결 오류로 영상 재생과 외형 반복 선택의 육안 검증은 완료하지 못했습니다. 새 수정본에서 문제가 계속되면 동일 화면으로 재확인이 필요합니다. 10월 23일 제보는 수정본 적용 전의 자료입니다.
