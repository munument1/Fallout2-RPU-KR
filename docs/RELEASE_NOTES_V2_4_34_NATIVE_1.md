# RPU Korean v2.4.34-native.1

## 변경 사항

- 이슈 #4 자막: 이전 영어 전용 `nar_2/3`을 포함한 34종의 남녀 엔딩 자막을 번역했습니다.
- 하단 메시지 기록창: 레저렉션 KR1.2에서 인게임 검증된 CP949 픽셀 폭 기준 줄바꿈 패치를 재사용했습니다.
- 공식 RPU v2.4.34의 `release/f2_res.dll`과 레저렉션 KR1.2의 원본 DLL이 SHA-256 `2d3c52cf624b22958db7fa44e3db71c2d0478503da5ceb40f0636dea1202fb5a`로 정확히 일치함을 검증했습니다.
- GitHub Actions에서 원본 해시, 패치된 DLL의 `.krfit` 섹션과 두 수정 진입점, CP949 번역 데이터, 최종 ZIP을 검사했습니다.

## 내려받기

- **`RPU-KR-v2.4.34-with-HRP-fix.zip`**: 공식 RPU 2.4.34용 통합 한국어판, HRP 수정 포함 (권장)
- `korean-classic-data.zip`: 번역 데이터만, 고해상도 패치 DLL 변경 없음
- `SHA256SUMS.txt`: 다운로드 파일 검사값

## 적용 방법

1. 공식 **RPU 2.4.34**가 설치된 Fallout 2 게임 루트를 백업합니다. 특히 원래 `f2_res.dll`을 보관하세요.
2. 다른 모드에서 자체 수정한 `f2_res.dll`을 사용하는 경우 **통합 ZIP 사용 금지**. 번역 전용 ZIP만 사용하세요.
3. 권장 통합 ZIP의 압축을 `fallout2.exe`가 있는 폴더에 풀어 덮어씁니다. `f2_res.dll`은 이 게임 루트에 설치됩니다.
4. 별도의 독립형 한국어 텍스트 엔진 **v1.2.3**을 사용하세요. 이전 엔진을 업그레이드해야 하는 경우 해당 설치기 지침에 따라 복구 후 재설치합니다.
5. 실제 게임에서 하단 메시지 기록창의 긴 한글과 엔딩 자막을 확인하세요.

이 통합 패키지는 공식 RPU 2.4.34 원본 HRP에만 맞춘 것입니다. 다른 버전의 HRP와 무조건 호환된다고 주장하지 않습니다.

**검증 한계**: 기존 레저렉션 KR1.2에서 같은 원본 DLL의 수정 효과를 인게임 확인했습니다. RPU 2.4.34에서 별도 장시간 인게임 검증까지 끝낸 것은 아닙니다.
